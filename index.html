22+ 组件

覆盖基础、表单、导航、反馈、数据展示五大分类，API 对齐 Element Plus。

JavaScript 优先

全部使用 JavaScript 编写，无 TypeScript 编译步骤，源码即文档，上手门槛低。

交互式文档

每个组件配有可运行的 demo 和源码展示，所见即所得。

可测试

核心组件配有 Vitest + jsdom 测试用例，覆盖渲染、交互、边界状态。

按需引入 / 全量安装

支持 app.use(Component) 按需注册，也支持 app.use(ToyElement) 全量安装。

Monorepo 管理

使用 pnpm workspace 管理 6 个子包，支持 components、core、hooks、theme、utils、constants 的协同发布。
