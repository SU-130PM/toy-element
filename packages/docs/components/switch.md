## Switch API

| 属性名 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `modelValue` | 绑定值 | `boolean \| string \| number` | `false` |
| `activeValue` | 打开时的值 | `boolean \| string \| number` | `true` |
| `inactiveValue` | 关闭时的值 | `boolean \| string \| number` | `false` |
| `disabled` | 是否禁用 | `boolean` | `false` |
| `size` | 尺寸 | `"large" \| "small"` | - |
