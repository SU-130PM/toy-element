Form 表单 ​

包含表单验证功能的表单容器。

基础用法 ​

完整的表单示例，包含必填校验和多种输入框。

用户名
邮箱
密码
简介

<template>
  <er-form ref="formRef" :model="formData" :rules="rules" label-width="100">
    <er-form-item label="用户名" prop="name">
      <er-input v-model="formData.name" placeholder="请输入用户名" />
    </er-form-item>
    <er-form-item label="邮箱" prop="email">
      <er-input v-model="formData.email" placeholder="请输入邮箱" />
    </er-form-item>
    <er-form-item label="密码" prop="pwd">
      <er-input v-model="formData.pwd" type="password" placeholder="请输入密码" show-password />
    </er-form-item>
    <er-form-item label="简介" prop="desc">
      <er-input v-model="formData.desc" type="textarea" placeholder="请输入简介" />
    </er-form-item>
    <er-form-item>
      <er-button type="primary" @click="submitForm">提交</er-button>
      <er-button @click="resetForm">重置</er-button>
    </er-form-item>
  </er-form>
</template>
<script setup>
import { ref, reactive } from "vue";
import message from "../../../components/Message/methods.js";
const formRef = ref();
const formData = reactive({ name: "", email: "", pwd: "", desc: "" });
const rules = {
  name: [
    { required: true, message: "请输入用户名", trigger: "blur" },
    { min: 2, max: 10, message: "长度在 2 到 10 个字符", trigger: "blur" },
  ],
  email: [
    { required: true, message: "请输入邮箱", trigger: "blur" },
    { type: "email", message: "请输入正确的邮箱格式", trigger: "blur" },
  ],
  pwd: [
    { required: true, message: "请输入密码", trigger: "blur" },
    { min: 6, message: "密码不能少于 6 位", trigger: "blur" },
  ],
};
function submitForm() {
  formRef.value?.validate((valid) => {
    if (valid) message({ message: "提交成功!", type: "success" });
  });
}
function resetForm() {
  formRef.value?.resetFields();
}
</script>

自定义触发时机 ​

通过规则的 trigger 字段控制验证时机：blur（失焦）、change（值变化）、或两者组合。

年龄
手机号
验证码

<template>
  <er-form ref="formRef" :model="formData" :rules="rules" label-width="100">
    <er-form-item label="年龄" prop="age">
      <er-input v-model="formData.age" placeholder="输入后即时验证" />
    </er-form-item>
    <er-form-item label="手机号" prop="phone">
      <er-input v-model="formData.phone" placeholder="失焦时验证" />
    </er-form-item>
    <er-form-item label="验证码" prop="code">
      <er-input v-model="formData.code" placeholder="即时+失焦双重验证" />
    </er-form-item>
    <er-form-item>
      <er-button type="primary" @click="submitForm">提交</er-button>
    </er-form-item>
  </er-form>
</template>
<script setup>
import { ref, reactive } from "vue";
import message from "../../../components/Message/methods.js";
const formRef = ref();
const formData = reactive({ age: "", phone: "", code: "" });
const rules = {
  age: [
    { required: true, message: "请输入年龄", trigger: "change" },
    { pattern: /^\d+$/, message: "年龄必须是数字", trigger: "change" },
  ],
  phone: [
    { required: true, message: "请输入手机号", trigger: "blur" },
    { pattern: /^1[3-9]\d{9}$/, message: "手机号格式不正确", trigger: "blur" },
  ],
  code: [
    { required: true, message: "请输入验证码", trigger: "change" },
    { len: 6, message: "验证码为 6 位", trigger: "blur" },
  ],
};
function submitForm() {
  formRef.value?.validate((valid) => {
    if (valid) message({ message: "提交成功!", type: "success" });
  });
}
</script>

属性名说明类型默认值

rules验证规则object—
labelWidth标签宽度string | number—
labelPosition标签位置"left" | "right" | "top""right"
labelSuffix标签后缀string—
disabled是否禁用所有子组件booleanfalse

hideRequiredAsterisk是否隐藏必填星号booleanfalse
requiredAsteriskPosition星号位置"left" | "right""left"

Form 方法 ​

方法名说明参数
validate(callback)验证全部字段(valid: boolean, invalidFields?) => void
validateField(keys, callback)验证指定字段keys: string[]
resetFields(keys)重置字段值keys?: string[]
clearValidate(keys)清除验证状态keys?: string[]

属性说明类型
required是否必填boolean
message验证失败提示信息string
trigger触发时机"blur" | "change" | string[]
min最小长度/最小值number
max最大长度/最大值number
len精确长度number
pattern正则匹配RegExp
type数据类型（如 "email"、"number"）string
validator自定义验证函数(rule, value, callback) => void
